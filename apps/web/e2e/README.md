# Browser API fixtures

From the repository root, run `make gate-ux-e2e` after installing the web
dependencies and Playwright Chromium. The command builds the production web
app, starts its own preview on loopback port 5209, runs scenarios 03–06 and stops
the preview afterward. It needs no running application API or PostgreSQL.

The preview uses a separate Vite configuration with no API or file proxy. The
scenario files intercept application API requests. The runner refuses an occupied
port, never reuses a live server, and does not accept `PLAYWRIGHT_BASE_URL`.
The usual application ports 5173 and 4252 are untouched.

Screenshots and failure output go to `hyperplane-browser-fixtures` under the
operating system's temporary directory. Set
`PLAYWRIGHT_OUTPUT_DIR` to keep a particular run in another folder. No HTML
report is generated by default.

These tests cover workflow authoring, saving, task progress, approval,
continuation and SDK read-model behavior with controlled API responses. The old
live-server navigation and data-dependent home smoke tests were removed; they
could pass against a different checkout and skipped assertions when data was
absent. The current suite does not claim live model quality or backend persistence.
Use the separate [real API browser journey](../e2e-live/README.md) for production
HTTP handlers, a disposable PostgreSQL database and deterministic SDK transport.
